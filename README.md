# Постоянный XML-фид для LIDLE

Фид содержит 50 реальных квартир: по 5 лотов в 10 жилых комплексах. Внутри каждого ЖК собрана маркетинговая витрина из пяти ролей:

1. `entry` — минимальный бюджет входа;
2. `optimal` — сбалансированный массовый вариант;
3. `value` — выгодная площадь относительно бюджета;
4. `family` — семейная планировка;
5. `premium` — верхний ценовой сегмент как ценовой якорь.

## Файлы

- `source/projects.json` — неизменяемые данные ЖК и фотографии;
- `source/lots.json` — 50 выбранных лотов;
- `lots.csv` — таблица для быстрой проверки и редактирования;
- `image_manifest.csv` — контроль обложек и количества фотографий;
- `generate_feed.mjs` — генератор XML;
- `validate_feed.mjs` — автоматическая проверка полноты;
- `lidle_feed_50.xml` — готовый файл для размещения по постоянному HTTPS-адресу.

Постоянный адрес фида: <https://ava7777.github.io/lidle-feed-50/lidle_feed_50.xml>

Репозиторий: <https://github.com/AVA7777/lidle-feed-50>

## Обновление

```bash
node generate_feed.mjs
node validate_feed.mjs
```

`internal-id` строится из ЖК, корпуса и номера квартиры. При обновлении цены или описания идентификатор сохраняется, поэтому импортёр обновляет объявление, а не создаёт дубль.

Цены и наличие меняются у застройщиков. Перед каждым очередным обновлением фида нужно сверять выбранные квартиры, затем заново запускать генератор и валидатор. Фотографии внутри одного ЖК ротируются: у пяти объявлений разные обложки; для лотов, где извлечена планировка, она становится первой фотографией.

## Статус подключения

14 сентября 2026 года URL подключён в разделе LIDLE `/feeds`. Импорт создал очередь из 50 карточек; автоматическое переписывание заголовков и описаний ИИ включено. Массовую публикацию следует выполнять после завершения счётчика «Обработано ИИ: 50 из 50» и выборочной проверки карточек.
